# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for a security problem.

Report it privately with [GitHub's "Report a vulnerability"](https://github.com/miniwall-app/miniwall-android/security/advisories/new) (Security tab of this repository). Include what you found, how to reproduce it, and which version you tested.

We aim to acknowledge a report within 7 days and to tell you what we plan to do about it. We will credit you in the fix notes unless you prefer not to be named.

## Supported versions

While the SDK is on `0.x`, only the latest release gets security fixes.

## Scope

In scope: this SDK's code and the way it handles screen data, links, input and network calls.
Out of scope: your own app, your checkout, and the Miniwall dashboard and API (report those through the same channel on the Miniwall website; do not test them without permission).
